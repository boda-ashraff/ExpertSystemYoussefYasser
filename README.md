# MediSense AI
نظام خبير تعليمي للتقييم الطبي المبدئي (HTML / CSS / JS فقط).

## التشغيل
افتح ملف `index.html` في أي متصفح (لا يحتاج خادم ولا تثبيت).

## الهيكل
- index.html : الصفحة الرئيسية والهيكل
- css/style.css : التصميم (RTL)
- js/app.js : قاعدة المعرفة + محرك الاستدلال + طبقة الطوارئ + الواجهة

## ملاحظات مهمة
- جميع القواعد والمصادر حاليا unverified وتحتاج مراجعة طبية قبل أي استخدام حقيقي.
- البيانات تُحفظ محليا في المتصفح (localStorage) فقط.
- Supabase / الحسابات / واجهة الإدارة غير منفذة في هذه النسخة.
